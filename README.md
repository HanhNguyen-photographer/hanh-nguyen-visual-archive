# Hanh Nguyễn — Ways of Seeing

Static bilingual photography website. No build process, paid hosting or custom domain needed.

## Preview
Unzip and open `index.html` in a browser. All photo paths are relative; JavaScript data is local, no JSON fetch needed. Google Fonts requires internet; system fallback is included.

## GitHub Pages
Use the existing public repository. Back up the old version (Code → Download ZIP). Replace old root index.html, style.css, script.js and upload data.js, assets/ and Hanh_Nguyen_CV.pdf. Keep assets as a folder, not loose files. A GitHub Desktop clone is the simplest way to copy the whole folder into the repository and commit/push. Settings → Pages → Deploy from a branch → main → /(root). Do not upload this ZIP itself. Do not delete the repository just to replace the site.

## Maintenance
`data.js` stores bilingual titles, captions, project grouping and image IDs. IDs 001–119 refer to the editorial master; V1-prefixed IDs refer to retained legacy images. The latter are separate to prevent identifier collisions. Do not expose internal editorial notes. Road to Home, Samsara and Where the Mountains Remember are project notes until verified images are supplied. The CV is the existing version. Contact: Hanh777diaz@gmail.com; Instagram: @hanhng and @_hanhdiuniverse_. Before public deployment, verify permissions and captions (especially funeral photographs, minors, collaborative works and older legacy entries). Sensitive series are gated in the UI, not private: files on a public repository remain publicly accessible. No copyright licence to reuse images is granted by this package.
